# Next steps after M4.6

The next implementation block should focus on an execution orchestrator that can consume autonomy-session items only through the permit broker and existing worker boundary, while preserving per-action audit/evidence and stop conditions. Candidate milestones: M4.7 execution batch receipts, M4.8 result-to-registry feedback, M4.9 bounded same-origin mapper, M5.0 passive test-family catalog, M5.1 proof-specific verifiers.

State-changing and intrusive test families remain out of the autonomous worker until explicit policy/approval contracts are implemented and field-tested.
