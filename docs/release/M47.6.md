# M47.6 — Bug Bounty Portfolio Orchestrator

M47.6 exposes `portfolio-plan` for operators working across multiple reviewed bug bounty programs.

The plan is deliberately non-executing. It gives every program an independent evidence namespace, preserves its own reviewed rate/policy state, rejects duplicate program IDs, and emits a deterministic fair queue order for programs that have no unresolved blocking policy issues.

No policy, permit, rate budget, or evidence chain is shared between programs.
