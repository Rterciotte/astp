# M47.2 — Unified stored-evidence assessment

M47.2 adds the first operator-facing assessment command that joins ASTP's existing offline assessment pieces without hiding the safety boundaries.

## Added

- `python -m astp.cli assess-stored-evidence`
- loads already-collected HTTP evidence from one directory;
- verifies evidence before using it;
- fingerprints observed technology;
- normalizes protocol/posture signals;
- builds conservative finding candidates;
- correlates findings without increasing proof state;
- writes a Markdown report and structured assessment outputs;
- performs no network request.

This command is intentionally an **offline assessment stage**. Planning and execution still use the existing scope → plan → permit → worker workflow.
