# M46.6 — Program-bound bounded field assessment entrypoint

M46.6 connects a fresh `EXECUTION_ELIGIBLE` program pre-flight to the existing permit-gated observation and offline assessment/report pipeline.

The first live profile is deliberately tiny: one exact HTTPS target, one GET, one fresh permit, at or below the reviewed numeric rate. It refuses stale/invalid pre-flight evidence, out-of-scope targets, state-changing/intrusive ceilings, and rate increases. It does not run broad scanners, brute force, exploit payloads, or state-changing actions.

For Smart Fit the operator wrapper defaults to `https://smartfit.com/`. The wrapper always performs a fresh live BugHunt pre-flight first, then prepares immutable assessment artifacts, executes the single bounded observation, and builds the report offline from stored evidence.
