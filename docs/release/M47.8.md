# M47.8 — Active Verifier Integration Pass

M47.8 exposes `plan-verification`, connecting stored HTTP evidence, verifier-depth signals, the verification planner/batch model, and the active verifier registry.

The command is intentionally planning-only. Proposals do not authorize requests. Active actions require normal policy review and a fresh permit. State-changing verifier families remain explicitly operator-gated and are never autonomously enabled by this workflow.

This closes the CLI integration gap without weakening the existing verifier execution gates.
