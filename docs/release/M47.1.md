# M47.1 — CTF Mode Foundation: Rules and Artifact Intake

M47.1 begins implementation of the previously documented CTF mode without adding an unrestricted solver.

The new `ctf-intake` command:

- validates a structured challenge definition;
- records whether challenge rules allow AI and automation;
- supports `disabled` or `declared_endpoints_only` network policy;
- requires declared endpoints when network policy allows them;
- restricts declared artifact paths to the challenge directory;
- hashes and inventories local challenge artifacts;
- performs no network action and launches no solver.

If AI or automation is prohibited by event rules, autonomous solving is blocked. Later CTF milestones must reuse ASTP's permit, isolation, evidence, audit, and budget boundaries.
