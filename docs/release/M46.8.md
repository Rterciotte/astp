# M46.8 — First-Class Offline JavaScript Analysis

M46.8 promotes the existing JavaScript static analyzer into the main ASTP CLI as `analyze-javascript`.

- accepts an already-retrieved local artifact;
- performs no network requests;
- hashes exact artifact bytes instead of re-encoded text;
- detects conservative API, route, absolute-URL, framework, source-map, and network-call hints;
- never labels a static-analysis signal as a confirmed vulnerability.

The older `python -m astp.javascript_static_cli` bridge remains compatible.
