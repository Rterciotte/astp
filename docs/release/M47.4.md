# M47.4 — Finding synthesis workflow

M47.4 exposes the existing evidence-backed finding pipeline as an operator command.

## Added

- `python -m astp.cli synthesize-findings`
- consumes an evidence-consumer summary;
- uses only signals explicitly eligible for finding candidacy;
- correlates duplicates;
- preserves the strongest evidence-backed proof state without proof inflation;
- keeps informational posture and technology clues out of findings by default.

The workflow remains offline. Retests and verification actions must return to normal policy evaluation and fresh permit issuance.
