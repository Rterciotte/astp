# ASTP M30.5–M32.4 — Field Qualification and E2E Rehearsal

This release separates runtime installation from field qualification, binds worker receipts to
engagement/action provenance, expands active-verifier execution gates, and adds an offline
end-to-end assessment rehearsal plus a strict v1 readiness gate.

The release does **not** mark physical browser/tool runtimes as field-qualified and does not
claim full pentest readiness by default.
