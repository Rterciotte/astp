# M46.7 — Permit-Gated Redirect Continuation

Version 0.463.0.

Adds evidence-derived redirect continuation for bounded field assessments. A prior response-backed redirect may become a candidate only when immutable provenance is valid, the redirect was not followed, a new permit is explicitly required, and the exact destination is inside the compiled source scope.

The continuation script performs no direct HTTP request. It invokes the existing bounded assessment entrypoint, which refreshes live pre-flight state and brokers a new exact-action permit before the single GET.
