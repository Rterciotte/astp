# M49.0 — ASTP 1.0 Release Candidate

M49.0 consolidates the Bug Bounty v1 and CTF lines into the first ASTP 1.0 release candidate (`1.0.0rc1`).

## Added

- `release-info` for offline version/milestone reporting.
- `release-readiness` as the final offline qualification gate.
- schema-backed validation of M48.0 Bug Bounty and M48.6 CTF acceptance artifacts.
- SHA-256 qualification artifact digests in the readiness report.
- `docs/SECURITY_MODEL.md` and `docs/RELEASE_CHECKLIST.md`.
- deterministic local CTF RC example suite covering all declared categories.

## Hardened

- synchronized package/project version metadata.
- release readiness requires Bug Bounty network-action/permit accounting to balance.
- release readiness requires CTF trace reproducibility rate of 1.0 and confirms local acceptance did not use the network branch.
- required 1.0 RC documentation/repository surface is checked before PASS.

No release command performs target network activity.
