# M47.5 — Final assessment package

M47.5 joins the existing reporting and assessment-bundle components into a final operator command.

## Added

- `python -m astp.cli finalize-assessment`
- packages the selected Markdown report, correlated findings, and evidence manifest;
- records SHA-256 hashes for package artifacts;
- records network-action and permit-consumption counts;
- immediately verifies the generated bundle;
- reports `VALID` or exits non-zero when integrity checks fail.

A package is marked assessment-complete only when the declared network-action and permit-consumption counts match.
