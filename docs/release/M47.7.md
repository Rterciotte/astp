# M47.7 — Authenticated / Browser Observation Integration

M47.7 exposes the existing authenticated observation boundary through `observe-authenticated-http`.

An `AuthSessionProfile` contains secret references and origin/identity bindings rather than raw credentials. At execution time the current runtime resolves supported references (currently environment-backed references) only at the transport boundary. Authenticated evidence is forced to the `sensitive` label.

The command keeps the same exact-action permit, rate, timeout, body-size, evidence-manifest, and optional raw-body persistence controls as normal HTTP observation. A session cannot be used outside its declared origins.
