# M47.9 — Recovery, resume, and crash acceptance

M47.9 closes the fail-closed recovery acceptance gap without adding any network behavior.

## Added

- `recovery-acceptance` in the main CLI.
- Deterministic interruption scenarios for:
  - before permit issuance;
  - after permit issuance;
  - after permit consumption;
  - worker failure;
  - after evidence persistence;
  - during report assembly.
- Acceptance checks for checkpoint integrity, tamper rejection, and policy-drift replan.

## Safety invariant

No interruption authorizes automatic network replay. A retry that could touch a target returns to planning and requires a fresh permit. Stored evidence and report assembly may resume offline where appropriate.
