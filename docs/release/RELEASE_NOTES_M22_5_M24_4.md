# M22.5-M24.4 — Isolated Runtime Packaging

This block adds immutable runtime artifact identities, exact worker launch envelopes, bounded browser/security-tool worker protocols, runtime health constraints, qualification planning, runtime bundle manifests, and an adaptive coordinator decision primitive that never grants network authority.

The Playwright and security-tool images are build blueprints only. Their bundle remains `operational_ready=false` until images are built, digest-pinned, permit-order tested, and field-qualified in an authorized environment.
