# Release notes — M34.5–M36.4

Version 0.351.0 adds physical Docker runtime build manifests, hardened shell-free Docker command compilation, worker image candidates, a complete physical qualification probe plan, provenance-bound qualification records, and a strict field-readiness gate.

No runtime is marked field-qualified by this release. Network field qualification must occur only in an explicitly authorized lab/engagement and must produce complete probe evidence.
