# M47.3 — Evidence consumer pipeline

M47.3 generalizes offline consumption of stored HTTP evidence and opt-in body artifacts.

## Added

- `python -m astp.cli consume-evidence`
- integrity-aware processing of stored evidence;
- HTML candidate extraction from `href`, `src`, and `action` attributes;
- JavaScript analysis through the M46.8/M46.9 static analyzer;
- JSON/API candidate extraction from URL/path-like string values;
- redirect-location candidates;
- header/protocol/posture normalization;
- body artifact size/SHA-256 verification before content analysis.

Every discovered target is emitted with:

- `requires_policy_review: true`
- `network_authorized: false`

No consumer performs network execution.
