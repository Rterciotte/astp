# M46.9 — Evidence-Bound JavaScript Artifact Analysis

M46.9 binds offline JavaScript analysis back to HTTP observation provenance.

When `analyze-javascript --evidence <observation.json>` is used, ASTP verifies that the local artifact SHA-256 and byte size match the persisted `body_artifact` reference before analysis output is bound to:

- source evidence ID;
- source permit ID;
- source target;
- verified artifact integrity.

A mismatch fails closed. The analyzer still performs zero network actions, and discovered URLs remain non-authorizing signals.
