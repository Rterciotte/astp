# ASTP M40.5-M42.4 — Adaptive Verification E2E

This overlay consumes qualified-runtime state as an admission prerequisite and connects observation-derived signals to hypotheses, bounded verifier candidates, fresh-policy/fresh-permit execution gates, proof progression, coordinator REPLAN semantics, and finding/report readiness.

The new rehearsal is intentionally offline. It does **not** self-certify production or program readiness and does not perform network or container execution.

State-changing verification remains non-autonomous. Without an exact action/target/verifier-bound approval, the modeled result is blocked with zero worker launch and zero network I/O.
