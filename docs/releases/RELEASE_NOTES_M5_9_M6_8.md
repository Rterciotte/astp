This block adds bounded evidence-driven iteration without broadening autonomous execution authority.

- M5.9 binds evidence feedback to one session and engagement.
- M6.0 rebuilds plans through the existing authorization engine.
- M6.1 admits only safe candidates inside the configured discovery depth.
- M6.2 stores canonical completed action identities in SQLite.
- M6.3 proposes GET after HEAD only for declared body-evidence needs.
- M6.4 catalogs passive/safe-active, non-state-changing web posture tests.
- M6.5 emits non-executing, permit-gated proof verification plans.
- M6.6 models explicit finding retest and resolution transitions.
- M6.7 round-robins bounded work across program queues.

The invariant remains `Planner -> Policy -> Permit -> Worker -> Evidence`. No new module performs network access.
