# M46.6a — Field execution failure semantics

M46.6a closes a bootstrap gap discovered during the first Smart Fit bounded field attempt.
A permit was issued, the HTTP observation produced immutable `failure_kind=dns` evidence, but the
legacy session command returned exit code 0 and the wrapper incorrectly continued into the offline
assessment/report pipeline.

The wrapper now requires response-backed success evidence before declaring the field assessment
complete. DNS failures are classified as `DNS_RESOLUTION_FAILED_BEFORE_TARGET_CONNECTION`, produce
an immutable execution-status artifact plus `execution-failure.md`, and stop before the normal
assessment report is built.

No retry, rate increase, scanner expansion, state-changing action, or authorization bypass is added.
